# 기업분석 PDF 리포트 skill

Version 2.0.0

근거 기반 기업분석 보고서와 PDF를 만드는 재사용형 skill입니다. 제공 자료를 기본으로 쓰며, 사용자가 요청하면 공공 원출처를 추가 조사·검증합니다. 입력 양식과 복사 가능한 프롬프트를 제공하고, 출처·투자내역·재무 차이·조건부 결론 및 PDF 가독성을 체계적으로 점검합니다.

## 설치

Codex 개인 skill 폴더에 이 저장소를 `company-report-pdf` 이름으로 clone합니다.

```powershell
git clone <repository-url> "$env:USERPROFILE\.agents\skills\company-report-pdf"
```

그 다음 Codex에서 `$company-report-pdf`를 호출하거나 기업분석 보고서/PDF 작성을 요청합니다. 업데이트하려면 이 폴더에서 `git pull`을 실행합니다.

ChatGPT에서도 Skills 기능이 제공되고 계정/워크스페이스에서 업로드가 허용된 경우, 사이드바의 **Plugins → Skills → Create → Upload from your computer**에서 skill ZIP을 올려 설치할 수 있습니다. 기능 제공 여부는 요금제와 워크스페이스 설정에 따라 다를 수 있습니다.

## 사용 흐름

1. 시작할 때 회사, 목적·독자, 기준일, 범위, 조사 허용 여부, 결과 폴더를 정리할 입력 양식과 복사 가능한 프롬프트를 제공합니다.
2. 출처 인벤토리와 추출한 사실을 검토하고 수정합니다.
3. 보고서 원고와 PDF 초안을 검토합니다.
4. 확정한 산출물을 프로젝트별 폴더에 보관합니다.

## v2 개선사항

- 공개자료 조사 요청 시 공시·정부·규제기관 등 원출처로 검증
- 회사 발표와 독립 확인 자료를 본문에서 명확히 구분
- 조건부 관찰의 판단 변경 요인과 필요한 정보 제시(임의 기준치 금지)
- 밸류에이션·희석·현금흐름·개발비 자료가 부족할 때 결론의 범위를 제한
- 투자 이력의 범위·합계 산식과 실제 납입/누적 조달액 간 구분
- 포털 표시·이미지 판독·계산·회사 원문 오류를 분리하는 재무 검증
- 검토 요청 전 자체 편집·근거·산술·PDF 부록 가독성 점검
- 단일 최신 검토본을 명확히 하여 불필요한 버전 난립 방지

회사별 원본 자료와 리포트는 이 skill 저장소에 넣지 않습니다. 이 저장소에는 재사용 가능한 지침과 범용 자료만 관리합니다.
