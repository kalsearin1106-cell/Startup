# 기업분석 PDF 리포트 skill

Version 2.1.0

제공 자료와 허용된 공개 근거를 바탕으로 한국어 또는 사용자가 지정한 언어의 기업분석 보고서와 PDF를 작성하는 Codex skill입니다. 입력을 반복해서 묻지 않고, 단계별 검토와 바로 초안 방식 중 사용자가 원하는 흐름으로 진행합니다.

## 설치 및 업데이트

Codex 개인 스킬 폴더에 저장소를 `company-report-pdf` 이름으로 복제합니다.

```powershell
git clone https://github.com/kalsearin1106-cell/Startup.git "$env:USERPROFILE\.codex\skills\company-report-pdf"
```

그 다음 Codex에서 `$company-report-pdf`를 호출하거나 기업분석 보고서/PDF 작성을 요청합니다. 이미 설치했다면 스킬 폴더에서 `git pull`을 실행해 업데이트합니다.

ChatGPT에서 Skills 업로드가 계정·워크스페이스에 허용된 경우, **Plugins → Skills → Create → Upload from your computer**에서 패키지를 설치할 수 있습니다. 기능은 계정과 워크스페이스 설정에 따라 다를 수 있습니다.

## 사용 흐름

1. **입력 정리:** 회사, 목적·독자, 기준일, 분석 범위, 자료 조사 권한, 언어·형식, 저장 폴더, 검토 방식을 간단히 확인합니다. 이미 대화나 첨부 자료에 있는 내용은 다시 묻지 않습니다. 필요하면 입력 양식과 복사 가능한 요청문을 사용합니다.
2. **자료 범위 선택:** 기본은 사용자가 제공한 파일과 링크만 쓰는 방식입니다. 공개자료 조사나 검증을 요청하면 공시·정부·규제기관·임상등록부·특허 데이터베이스 등 원출처를 찾아 실제 내용을 확인합니다.
3. **검토 흐름 선택:**
   - **단계별 검토:** 자료 목록, 주요 추출 사실과 근거 위치, 모호한 점·누락 자료를 먼저 보여줍니다. 사용자가 검토한 뒤 보고서 초안을 작성합니다.
   - **바로 초안:** 자료 인벤토리와 내부 사실 확인은 그대로 진행하고, 첫 번째 검토 응답을 기다리지 않고 초안을 작성합니다. 미해결 항목은 보고서에 표시합니다.
4. **보고서 초안과 내부 검수:** 편집 가능한 Markdown, 출처 목록, 필요한 차트와 PDF 초안을 만듭니다. 두 번째 검토 전에 근거 위치, 수치 계산, 본문·표·차트 간 일치, 맞춤법, 링크와 PDF 가독성을 자체 확인합니다.
5. **PDF 검토:** 보고서 원고와 렌더링한 PDF 미리보기를 보여주고, 사용자의 판단이 필요한 수정 사항을 확인합니다. 이 최종 검토는 두 진행 방식 모두에 포함됩니다.
6. **저장:** 검토된 결과물을 프로젝트별 폴더에 저장하고 현재 검토본을 분명히 표시합니다. 회사별 원본 자료와 보고서를 스킬 저장소에는 넣지 않습니다.

**바로 초안**은 첫 번째 인벤토리 검토 응답을 생략하는 선택입니다. 근거 확인과 내부 검수, PDF 초안의 최종 검토까지 생략하는 뜻은 아닙니다.

## v2.1.0 변경사항

- 핵심 스킬 지침과 근거 검토 절차를 한국어로 제공
- 한국어 요청 시 대화, 자료 인벤토리, 사실대장, 보고서도 한국어로 작성
- 원화·외화 단위와 번역 주장을 원자료까지 추적하는 기준 추가
- 단계별 검토와 바로 초안 방식의 차이 및 공통 최종 PDF 검토 단계 설명
- 설치·업데이트 안내와 복사 가능한 요청문을 새 사용 흐름에 맞게 정리

## 이전 버전의 v2 기능

- 공개자료 조사 요청 시 공시·정부·규제기관 등 원출처로 검증
- 회사 발표와 독립 확인 자료를 본문에서 명확히 구분
- 조건부 관찰의 판단 변경 요인과 필요한 정보 제시(임의 기준치 금지)
- 밸류에이션·희석·현금흐름·개발비 자료가 부족할 때 결론의 범위 제한
- 투자 이력의 범위·합계 산식과 실제 납입·누적 조달액 간 구분
- 포털 표시·이미지 판독·계산·회사 원문 오류를 구분하는 재무 검증
- 사용자 검토 전 편집·근거·산술·PDF 부록 가독성 자체 점검

회사별 원본 자료와 리포트는 이 skill 저장소에 넣지 않습니다. 이 저장소에는 재사용 가능한 지침과 범용 자료만 관리합니다.
