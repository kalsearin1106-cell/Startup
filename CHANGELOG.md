# Changelog

## 2.1.0

- Translated the core skill instructions and evidence-review workflow into Korean.
- Set Korean as the response and report language when the user requests in Korean, while preserving support for other requested languages.
- Added guidance for preserving original currency units and tracing translated claims to their source.
- Clarified the difference between staged review and direct-draft modes, including their shared internal QA and final PDF review.
- Rewrote the README workflow and copyable intake prompt to explain the current process.

## 2.0.0

- Added a compact intake form and copyable Korean request prompt.
- Enabled public-source research when the user explicitly requests it, with primary-source preferences and provenance.
- Added visible distinctions between company statements, official records, press reporting, and analysis.
- Added financial discrepancy triage to distinguish OCR/transcription/portal/calculation issues from filing errors.
- Added investment-history completeness and sum-scope rules.
- Added conditional-conclusion framework tied to clinical, contract, valuation/dilution, cash-flow, and development-budget evidence without invented thresholds.
- Added separate operating, investing, and financing cash-flow analysis guidance.
- Added pre-review editorial QA and appendix legibility/page-balance checks.
- Added current-version guidance to avoid near-identical final-file proliferation.
- Updated the ChatGPT skill-installation guidance where Skills upload is available.
